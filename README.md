# APPDEV1 Final Practical Exam

This project recreates the Sign Up and Login pages from the supplied Figma design using React and Vite. It uses CSS modules for each page, shared design tokens in `src/root.css`, and the shadcn/ui Input component for the text fields.

## Run locally

```bash
npm install
npm run dev
```

Open the app in your browser. The forms are visual designs and do not submit data.

## Reflection

We had already practiced React, CSS, and Git in class, so this final examination was a chance to use what we knew. I mostly focused on the important parts: following the instructions in order, matching the Figma design, and finishing each step before moving on. I began with the image and page layout, then added the title, form, and bottom section one at a time. That made the work easier to follow.

The screenshots helped me notice the details that mattered. A page could have all the right elements and still look different because of the spacing, font size, or input shape. I compared each stage with the reference and adjusted those details as I went. When I reused the Sign Up page for Login, I checked the copied labels and fields so the second page showed the right content.

I also tried to keep the code useful and simple. I put repeated styling values in `root.css` so the two pages would stay consistent. Later, I used the shadcn/ui Input component as required and checked that it kept the same appearance. I focused on the design work the exam asked for instead of adding extra form features.

Looking back, the useful part of this exam was applying lessons we already learned to a complete project. The screenshots and commits helped me stay organized and catch small mistakes. I am glad I focused on what the task needed and finished it step by step.
